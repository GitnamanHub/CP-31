## Purpose

This repository is a practice archive for building consistency with algorithms, data structures, and problem-solving under constraints.

## Working with solutions

For a useful long-term reference, each solution can include:
- The original problem link
- The key observation or algorithm
- Time and space complexity

## Language

C++

## Compile a standalone solution

With a C++17 compiler, use a command like:

```bash
g++ -std=c++17 -O2 -Wall -Wextra solution.cpp -o solution
./solution
```

Replace `solution.cpp` with the relevant source filename. Some online-judge problems require their own input format or driver code.
